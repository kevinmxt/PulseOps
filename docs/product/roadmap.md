# PulseOps 路线图

## 当前阶段
Phase 0 已完成；下一阶段为 Phase 1 — HTTP 监控核心。

## 阶段顺序

### Phase 0：工程初始化
- [x] 检查现有仓库、开发环境和 Git 状态
- [x] 初始化 Java 21 / Spring Boot / Maven Wrapper
- [x] 配置 PostgreSQL 与 Flyway
- [x] 初始化 Vue 3 + TypeScript + Vite
- [x] 配置本地 Docker Compose
- [x] 建立 README 和基础测试流程

完成条件：新环境按文档可以启动；数据库迁移和基础构建成功；仓库没有真实凭证。

### Phase 1：HTTP 监控核心
- [ ] Monitor CRUD
- [ ] URL 与配置校验
- [ ] 定时探测
- [ ] 超时、状态码与错误分类
- [ ] CheckResult 持久化
- [ ] 基础监控状态查询

完成条件：正常、失败、超时场景可重复测试；禁用监控不再执行；重启后配置仍存在。

### Phase 2：Incident 与通知
- [ ] 连续失败阈值
- [ ] 连续成功恢复阈值
- [ ] Incident 创建、去重和恢复
- [ ] Telegram 通知
- [ ] 通知状态、有限重试和日志

完成条件：不会为同一持续故障重复创建 Incident；通知故障不阻塞探测；恢复事件正确关闭。

### Phase 3：Heartbeat
- [ ] 心跳监控项
- [ ] 高强度随机令牌及安全存储
- [ ] 心跳上报接口
- [ ] 超时扫描
- [ ] 故障与恢复通知

完成条件：有效令牌可上报，无效/撤销令牌被拒绝；超时可触发故障；重复扫描不会创建重复事件。

### Phase 4：界面、认证与数据维护
- [ ] 监控项列表、详情和编辑
- [ ] 历史分页与故障列表
- [ ] 基础认证与授权
- [ ] 历史数据保留策略
- [ ] 数据清理任务
- [ ] 备份与恢复演练

完成条件：核心功能可从 UI 使用；未授权访问被拒绝；清理任务遵守保留期限；备份可恢复。

### Phase 5：VPS 部署
- [ ] 生产 Compose 配置
- [ ] Caddy / HTTPS
- [ ] 防火墙与 SSH 安全
- [ ] 日志轮转
- [ ] 数据库备份
- [ ] 外部健康检查
- [ ] 升级与回滚文档

完成条件：HTTPS 可访问、数据库不暴露公网、重启可恢复、备份可恢复、连续运行 7 天且无未解决的严重故障。

### Phase 6：试用验证
- [ ] 至少 5 个真实监控目标
- [ ] 邀请 3–5 位开发者试用
- [ ] 收集真实反馈
- [ ] 记录误报、漏报和告警延迟
- [ ] 输出下一阶段决策

## 路线图规则
- 按阶段顺序推进；若要调整顺序，记录原因。
- 未满足验收条件不得标记完成。
- 不伪造测试、运行或用户反馈证据。
- 当前阶段只实现必要功能，不提前实现未来阶段。
- 每次任务结束后，只更新实际发生变化的状态。
